# shae's tide 2 wiki 🎣

A cozy little wiki for the **Tide** mod (Minecraft 1.21.1, Fabric) — made with love by shae.

Everything about the mod in one place:

- 🐟 **Fish dex** — every fish, where to find it, how big it grows
- 🎒 **Items, blocks & recipes** — all the gear and how to craft it
- 🧺 **Crates & loot** — what's hiding in each crate
- 🎣 **Loadout planner** — pick a fish, get the perfect rod, hook, bobber, line & bait
- 📊 **Stats & formulas** — how luck, fish size and the catch minigame really work
- ⚙️ **Config, commands, advancements & compatibility**

## Find it

**Online:** https://shae-mxw0.github.io/shaes-tide-2-wiki/

**Offline:** grab the folder, open `index.html` — no server, no setup.
